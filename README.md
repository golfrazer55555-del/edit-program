# 싹둑 영상 편집기

설치 없이 브라우저에서 바로 쓰는 영상 편집 프로그램입니다.
영상·사진·음악을 불러와 자르고 이어 붙이고, 자막과 배경음악을 넣은 뒤 MP4 또는 WebM 파일로 내보냅니다.
파일은 어디에도 올라가지 않고, 모든 처리가 내 브라우저 안에서 이루어집니다.

## 실행하기

빌드 과정이나 설치할 패키지가 없습니다.

- **바로 열기**: 저장소를 내려받아(Code → Download ZIP) 압축을 풀고 `index.html`을 Chrome이나 Edge로 엽니다.
- **로컬 서버**: 저장소 폴더에서 아래 명령을 실행한 뒤 http://localhost:8000 에 접속합니다.

  ```bash
  python3 -m http.server 8000
  ```

- **GitHub Pages**: 저장소 Settings → Pages에서 이 브랜치를 배포 대상으로 고르면 몇 분 뒤 웹 주소가 생깁니다.

처음 열면 예제 프로젝트가 보입니다. 재생해 본 뒤 **가져오기**로 내 영상을 불러오면 새 프로젝트로 시작합니다.

## 기능

| 구분 | 할 수 있는 것 |
| --- | --- |
| 불러오기 | 영상(MP4, WebM, MOV), 사진(JPG, PNG, WebP), 음악(MP3, WAV, M4A, OGG), 자막(SRT, VTT). 화면에 끌어 놓기도 됩니다. 처음 불러온 영상의 비율(가로·세로·정사각형)로 화면이 맞춰집니다. |
| 타임라인 | 텍스트 레이어 · 영상 트랙 · 오디오 레이어. 클립을 끌어 순서 바꾸기, 양 끝을 끌어 길이 조절, 재생헤드 위치에서 분할, 삭제, 복제, 자석(클립 끝·재생헤드에 붙기), 확대/축소, 실행 취소/다시 실행 |
| 영상·사진 | 속도 0.25×–4×, 볼륨 0–200%, 음소거, 페이드 인/아웃, 전체 보이기/꽉 채우기, 크기·위치·회전, 움직임 효과(천천히 확대·축소·이동), 필터 8종과 밝기·대비·채도·흐림 |
| 텍스트 | 제목·자막·강조 프리셋, 한글 글꼴 8종, 크기·색·외곽선·배경 상자·그림자, 등장 효과(페이드·슬라이드·팝·타자기), 미리보기에서 끌어서 위치 이동 |
| 오디오 | 배경음악 볼륨·페이드·속도, 파형 표시. 영상 파일을 오디오 줄에 놓으면 소리만 씁니다. |
| 내보내기 | MP4 또는 WebM, 1080p·720p·480p, 24·30·60fps, 화질 3단계. 진행률과 남은 시간 표시, 중지, 결과 미리보기 후 저장 |
| 그 밖에 | 자동 저장(새로고침해도 작업과 파일이 남음), 방송용 안전 영역 표시, 단축키, 휴대폰·태블릿 화면 |

## 알아 두면 좋은 점

- **내보내기는 실제 속도로 녹화합니다.** 브라우저의 MediaRecorder로 영상을 처음부터 끝까지 재생하며 녹화하므로, 10분짜리 영상은 내보내는 데 약 10분이 걸립니다. 끝날 때까지 탭을 화면에 띄워 두세요.
- **MP4로 저장되는지는 브라우저에 달려 있습니다.** 최신 Chrome·Edge·Safari는 MP4(H.264)로, Firefox는 WebM으로 저장됩니다. 내보내기 창에는 그 브라우저가 지원하는 형식만 나옵니다.
- 브라우저가 재생하지 못하는 코덱(일부 아이폰 HEVC `.mov`, HEIC 사진)은 열리지 않습니다. MP4(H.264)나 JPG로 바꿔서 불러오세요.
- GIF는 첫 장면만 정지 화면으로 쓰입니다.
- 색 보정은 캔버스 필터를 지원하는 브라우저(Chrome, Edge, Firefox)에서만 적용됩니다.
- 자동 저장은 지금 쓰는 브라우저 안에만 남습니다. 다른 기기로 옮기려면 내보낸 영상 파일을 쓰세요.

## 파일 구조

```
index.html        화면 구성
css/style.css     스타일
js/util.js        공용 도구, 상수(비율·글꼴·필터), 알림·대화상자, 파일 저장
js/store.js       프로젝트 데이터 모델, 실행 취소/다시 실행
js/media.js       파일 정보 읽기, 썸네일·필름스트립·파형 만들기
js/engine.js      재생 엔진: 미리보기 합성, 여러 영상의 동기화, 오디오 믹싱
js/timeline.js    타임라인 화면과 끌기·길이 조절·자석·확대
js/inspector.js   속성 패널
js/library.js     미디어 목록
js/exporter.js    내보내기(MediaRecorder), WebM 길이 정보 보정
js/persist.js     자동 저장(IndexedDB)
js/sample.js      처음 화면의 예제 프로젝트(그림과 음악을 브라우저에서 생성)
js/app.js         버튼·단축키·파일 가져오기·화면 배치 연결
```

모듈 번들러 없이 `<script>` 태그 순서대로 불러오는 평범한 자바스크립트라서, `index.html`을 파일로 바로 열어도 동작합니다.
